# StasisFishingRod 💣🎣✨

Bind your **fishing rods** to **lodestones** and **teleport anywhere in the world**! 🌍🚀  
Right-click a **lodestone** with a **rod** to **sync it** — the **rod glows** to show it’s ready. Then, anywhere, right-click with that **rod** to **teleport back**! Break the **lodestone** and the **rod loses its connection** ❌. **Multiple rods + lodestones supported** 🎉  

---

## 🚀 Features 🌟
- `/stasis` ✨ → Make a **lodestone glow** and ready to **bind**  
- Right-click a **lodestone** with a **fishing rod** 🎣➡️🪨 → **Sync rod** to **lodestone**  
- **Teleport anywhere** 🌌 using the **synced rod**  
- **Multiple lodestones & rods supported** 🔗  
- **Fishing rods glow** 💡 to show they’re **synced**  
- **Cooldown** ⏱️ with **particles 💫** and **sound 🔊**  
- **Broken lodestone detection** ❌ → **rod loses sync**  

---

## 📜 Commands
| Command     | Description                                         |
|-------------|-----------------------------------------------------|
| `/stasis`   | ✨ Enable a **lodestone** for **stasis teleportation** |

---

## ⚡ Installation
1. Download the latest **JAR** and place it in your server’s `plugins` folder 📥  
2. Start or restart your **Paper server** 🔄  
3. Hold a **lodestone** and run `/stasis`, then **bind a fishing rod** 🎣🪨
